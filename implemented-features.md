## Итерация P0 + UI (прототип)
### Логика
- Курсы паруса: пороги 30° / 90° / 150°; без `sailBokovoy` в логе.
- Высадка только на клетки из `state.landable` (`Vector2i`).
- `IslandActions`: `spend_turn` — ход не тратится, если остров не найден или flooded.
- Старт партии только по кнопке «Отчалить» (не в `_ready`).
- Смертность 0.012/ход; потоп ступенчатый — годы 1–4 → +1 локтя/год, 5–8 → +2, 9+ → +3 (см. [Потоп](./flood.md#скорость-изменения-уровня-воды)); `END_CREW` при team wipe.
- Удалён мёртвый `crewMin` у кораблей (используется `sailReq`).
- MP под парусом считаются в единой точке — `Balance.sail_mp(ship_def, crew, strength)` (`sail · min(1, crew/sailReq) · strength`); `Actions.try_move` зовёт его, `Reachability` дублирует формулу inline для скорости.
- Потоп ступенчатый по годам через `year_bonus` в `Turn._apply_season_end`: 0.0 при годах 1–4, 1.0 при 5–8, 2.0 при 9+ — складывается с базовым `rise` сезона Ахет.
### Визуал
Шрифты: Forum-Regular.ttf (OFL) — заголовки; Inter-Variable.ttf (OFL) — UI/body. Cinzel-Variable.ttf ранее использовался как заголовочный, сейчас не подключён. SourceSans3-* и TwemojiMozilla удалены.
- Иконки HUD: не эмодзи, а процедурные глифы `IconGlyph` (`scripts/icon_glyph.gd`) — парус, весло, час, Imago Mundi, двойная сетка.
- Единые токены панели/кнопок; HUD, лог, модал, старт, финал.
- Карта: контраст суши/затопления, landable pulse, без reachable-dots.
- См. `ui-style.md`, `prototype-mechanics.md`.
